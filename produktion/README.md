# Produktion

Hier liegen die Arbeitsergebnisse je Video: Research-Brief, Skript,
QS-Protokoll und das Produktionsprotokoll. Ein Ordner pro Video.

| Ordner | Inhalt | Status |
|---|---|---|
| [`pilot-001/`](pilot-001/README.md) | Testdurchlauf der Pipeline am Fall „Northeast Blackout 2003" | Format- und Prozesstest; von der QS zurückgegeben (Belege fehlen) |

## Ablauf je Video

1. **Research-Brief** ([Agent](../agents/research.md)) → `research-brief.md`
2. **Skript** ([Agent](../agents/skript.md)) → `script.md`
3. **QS-Protokoll** ([Agent](../agents/qualitaet.md)) → `qs-protokoll.md`
   – bei Rückgabe zurück zu Schritt 2
4. **Produktion** (Mensch): Sprecheraufnahme, Grafik, Schnitt
5. **Upload-Freigabe** (Mensch, harte Grenze) → veröffentlichen
6. **Produktionsprotokoll** → `protokoll.md`, Vorlage unten
